Questions

Is this the official Teletalk app?

No. It's an independent concept app. It shows the same public job, notice and result information as alljobs.teletalk.com.bd, and you apply on the official Teletalk application sites.

Is it safe to install from outside the Play Store?

Every version is signed with the same key, and Android only installs updates signed with that key. The in-app updater downloads only from this project's GitHub releases and checks the file's fingerprint before installing.

Can I use my existing Alljobs account?

Yes. Sign in with the email or mobile number and password you use on alljobs.teletalk.com.bd. Your password goes only to alljobs.teletalk.com.bd; the app keeps just your sign-in session on your phone.

How do I update the app?

You don't have to do anything. The app checks for new versions and offers to install them. You can also check any time from Profile → Settings → App version.

Does it cost anything?

The app is free. Job application fees are paid to Teletalk as shown in each circular, never through this app.

I found a bug or have an idea.
